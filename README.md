# 📌 NULLTRACER // INVESTIGATION BOARD

A dark corkboard investigative dashboard built to track suspect dossiers, pin evidence, and map core computer science principles into a fun crime-inspired interface.

🔗 **Live Deployment:** https://threerd-sem-profiling-investigation.onrender.com

---

## ⚙️ Core Academic Objectives & Mapping

- **DBMS:** SQLite relational architecture linking `profiles` to `evidence_logs` via foreign keys, supporting full CRUD operations and persistent storage.
- **DSA:** Custom Max-Heap priority engine built from scratch that performs $O(\log n)$ priority sorting to dynamically surface the top-risk suspect.
- **OOP:** Polymorphic verification system utilizing an abstract base class (`EvidenceItem`) and specific subclasses (`CCTVLog`, `AccessLog`, `FinancialLog`).
- **ML:** Integrated with scikit-learn (`TfidfVectorizer` and `cosine_similarity`) to analyze and correlate witness notes against suspect threat payloads.
